# Project Context: mintool-crx

이 문서는 AI 에이전트가 현재 프로젝트의 고유한 배경과 진행 상황을 파악하기 위한 전용 공간입니다.

## 1. 프로젝트 개요
- **목적**: 다양한 웹사이트(GitHub, TossInvest, Jira 등)에서의 생산성 향상 및 광고 차단, DOM 조작 등의 기능을 제공하는 다목적 도구 상자(Toolbox) 크롬 확장 프로그램입니다.
- **주요 기능**:
    - **GitHub 확장**: PR 커밋 자동 임베드, 알림 필터링, 단축키 등.
    - **광고 차단**: `declarativeNetRequest` 및 사용자 정의 스크립트를 통한 광고 탐색 및 제거.
    - **DOM 관리**: 요소 제거/숨기기 및 Undo 기능. 별도의 **숨기기 모드**에서 visibility 미리보기로 선택한 규칙을 저장·재적용할 수 있습니다.
    - **사이트 커스텀**: TossInvest, Jira 등 특정 사이트 맞춤 기능.
    - **QA 시나리오**: (분석 중) QA 테스트 및 자동화를 위한 시나리오 스크립트 실행 기능으로 추정.

## 2. 진행 상황 및 히스토리
- **초기 상태**: MV3 기반으로 개발되었으며, `lib/` 폴더에 공통 유틸리티와 컴포넌트가 모여 있습니다.
- **현안**: `qa-scenario/script.js` 등 일부 파일이 매우 커져 있어 모듈화가 시급한 상태입니다.
- **아키텍처 도입**: `.agent/` 폴더를 통해 AI 협업 지침 및 표준 아키텍처 가이드라인이 도입되었습니다.

## 3. DOM 숨김 규칙 (선택·저장)

- 시작: 우클릭 → MinTool → **숨기기 모드 (선택·저장)**, 또는 팝업의 **숨기기 패널 열기**. 확장 업데이트 뒤에는 대상 페이지도 새로고침합니다.
- 요소 위에서 **원본이 보이는 반투명 덮개**로 미리보고 클릭하면 후보에 추가됩니다. 미리보기는 원본의 visibility/opacity/DOM을 바꾸지 않습니다. 저장 후에만 visibility:hidden으로 실제 가립니다. 기본 제안은 동일한 광고 속성/클래스의 그룹이며, 현재 선택과 매칭 개수를 표시합니다.
- 기본 패널은 약 **320px 폭 / 12px 본문 / 11px 보조 정보**의 요약형입니다. 후보는 번호·selector·매칭 수·사용 여부를 한 줄로 보여주며, **⌖**로 위치를 보고 **▸**로 selector/범위/삭제를 펼칩니다. 펼침 상태는 행 수정 중에도 유지됩니다. 도움말·새 후보 기본 범위와 JSON 저장소는 기본 접힘입니다. 저장/취소와 오류는 하단에 유지됩니다.
- **F2**: 대상 고정/해제. **↑/↓** 또는 버튼: 바깥/안쪽 요소 선택. 제목 영역을 드래그하여 패널을 이동할 수 있고, 접어도 위치를 유지합니다. 확장/리사이즈 시 화면 안으로 보정합니다. **Esc/취소**: 미저장 초안과 미리보기 복원.
- 다시 열면 **현재 페이지 전용 + 사이트 공통 규칙**을 비활성 항목까지 불러옵니다. 각 행에서 selector·범위·사용 여부를 편집하거나 제거할 수 있습니다. 다른 페이지 전용 규칙은 편집하지 않습니다.
- 페이지 범위는 pathname + query 일치(hash 제외), 사이트 범위는 정확한 origin 일치입니다. 새 후보 범위 선택은 신규 항목에만 적용되며 기존 규칙의 범위는 유지합니다. 수정/전체 제거도 **저장하고 적용** 전에는 초안입니다. 취소하면 최신 저장본을 복원합니다. 다른 곳에서 편집 대상 규칙을 변경했다면 오래된 초안의 저장을 거부합니다.
- 후보에는 세션 동안 유지되는 **#번호**를 부여합니다. 추가/수정한 행은 강조·목록 스크롤로 식별하고, 페이지의 선택 윤곽에도 같은 번호를 표시합니다. **위치 보기**로 해당 규칙의 첫 표시 가능한 영역을 다시 찾을 수 있습니다.
- 기본 접힌 **저장소 미리보기**는 chrome.storage.local의 domHideRulesV1 전체 저장값을 읽기 전용 JSON으로 보여줍니다. 다른 기능의 키나 미저장 초안을 섞지 않으며, 외부 저장 변경은 JSON에 반영하되 편집 중인 초안을 덮어쓰지 않습니다.
- 저장된 숨김 영역에는 작은 dot이 표시됩니다. hover/포커스 시 **Show / Hide**, 클릭/키보드로 **그 요소 하나만 일시 표시**합니다. 저장 규칙은 바뀌지 않고 새로고침하면 다시 숨깁니다. 편집 중에는 dot을 감추고 초안을 미리보며, 취소 시 기존 일시 표시 상태도 복원합니다. 중첩 매칭은 바깥 숨김 영역에 dot 하나만 표시합니다.
- 규칙별 편집/사용 여부/삭제는 패널에서만 관리합니다. 툴바 팝업은 기존 **현재 탭을 팝업으로 열기 → 설정** 메뉴 뒤에 **상태 점 + 숨기기 패널 열기** 한 행만 추가합니다. 기존 글꼴·행 높이·hover·구분선을 재사용하며 별도 카드나 규칙 목록은 두지 않습니다.
- 녹색 점은 기능이 켜져 있고 **현재 URL에 활성 규칙이 있음**을 뜻합니다. 회색 빈 점은 활성 규칙이 없거나 기능이 꺼진 상태입니다. 이는 실제 숨긴 DOM 수가 아닌 **설정 기준**이며, tooltip과 접근성 설명에 활성 규칙 수/비활성 이유를 표시합니다. 저장/기능 설정/SPA URL 변경 시 갱신하고 오래된 응답은 무시합니다.
- 오른쪽 **⋯**를 열면 **이 사이트 전체 해제**가 같은 메뉴 스타일로 나타납니다. 같은 origin의 다른 페이지 전용 규칙까지 enabled:false로 저장하지만 레코드나 다른 설정은 삭제하지 않습니다. 현재 페이지에 활성 규칙이 없어도 다른 페이지 규칙이 켜져 있으면 사용 가능합니다. 원래의 개별 on/off 조합을 기억하는 일시 중지 기능은 아닙니다.
- 설정의 **DOM 숨김 규칙**을 끄면 열린 선택 모드와 적용 스타일도 해제됩니다. 꺼진 동안 팝업의 패널 진입은 비활성화되지만 전체 해제는 저장된 활성 규칙이 있으면 사용할 수 있습니다. HTTP(S) 이외 페이지에서는 숨김 관련 진입/추가 작업을 비활성화합니다.

### 책임 경계와 파일

- `configs/dom-hider.global.js`: 저장 키·메시지·후보 속성·제한 및 panelWidth/previewOpacity의 정의.
- `services/dom-hider/rules.global.js`: 규칙 검증/범위 매칭/실제 숨김 visibility CSS의 단일 정의. 미리보기 표현과 실제 적용을 구분하여 저장 동작의 의미를 유지합니다.
- `selector.global.js`: CSS.escape를 적용한 요소/그룹 후보 생성. 개별 선택의 위치 경로는 루트나 고유 ID에 고정합니다. dot과 미리보기의 바깥 매칭 영역 선정은 outermostRuleTargets로 공유하여 중첩 대상에 덮개가 중복 적용되지 않게 합니다.
- `picker.global.js` + `picker-ui.global.js`: 편집 초안과 요약형 closed Shadow DOM 패널. 다른 사이트의 저장 규칙을 포함할 수 있는 JSON을 페이지 스크립트가 일반 DOM 탐색으로 읽지 못하게 합니다. 브라우저 검증은 확장의 isolated world에서 chrome.dom.openOrClosedShadowRoot를 사용합니다. 선택 모드에서는 저장 CSS가 중지되고 원본은 그대로 보입니다. hit-test는 잠깐 UI만 제외하므로 원본 스타일을 매번 켜고 끌 필요가 없습니다. 투명 입력층으로 iframe 클릭을 막고 바깥 호스트를 선택합니다.
- `preview.global.js`: 원본을 수정하지 않는 반투명 덮개와 후보 번호. DOM/크기/스크롤 변화에 맞춰 갱신하고, IntersectionObserver의 실제 교차 사각형으로 스크롤 컨테이너의 잘린 부분까지 보정합니다. cancel/save 시 레이어·관찰자·이벤트를 정리합니다.
- `storage.background.js`: chrome.storage.local의 `domHideRulesV1`을 소유하는 단일 쓰기 경로. 여러 탭의 read/modify/write를 직렬화하고, 편집 저장은 `ruleSnapshot`으로 현재 페이지 관련 규칙의 변경 여부를 확인한 뒤 원자적으로 병합합니다. 다른 페이지/사이트 규칙은 보존합니다.
- `markers.global.js`: Shadow DOM의 별도 dot/툴팁 UI. 대상 요소에 버튼이나 position 스타일을 넣지 않아 iframe 자체도 지원합니다. 일시 표시 속성을 숨김 CSS의 예외로 처리하며, visibility:visible을 강제하지 않아 사이트가 원래 숨긴 자손은 유지합니다. DOM/크기/교차 관찰과 scroll/resize를 rAF로 묶어 처리합니다. 기능 해제 시 dot·이벤트·관찰자·표시 속성을 정리합니다.
- `utils/content-isolated/draggable.global.js`: 기존 스타일 편집기와 공유합니다. viewport 제한은 옵션이며, 종료 시 destroy()로 드래그 이벤트를 정리하고 원래 body cursor/user-select를 복원합니다.
- `content-isolated.js`: 저장/기능 설정 변경과 SPA 경로 변경에 맞춰 재적용. CSS가 나중에 생긴 매칭 요소도 가립니다. 요소별 영구 rAF 루프를 만들지 않습니다.
- `popup/dom-hide-rules.js`: 현재 페이지 활성 상태, 패널 진입, 접힌 사이트 전체 해제만 담당합니다. 개별 규칙 관리는 패널과 중복하지 않으며, 페이지 UI를 잘못 숨겨도 접근 가능한 복구 경로를 유지합니다.

### 지원 범위와 검증

광고 자동 판별이나 네트워크 차단 기능이 아닙니다. 확인한 selector를 visibility:hidden으로 적용하며 DOM·iframe과 공간은 제거하지 않습니다. 기존 DOM 가리기/제거/Ad Block과 별도 기능입니다. iframe 내부 문서나 Shadow DOM 내부의 선택은 지원하지 않으며, 광고 전체는 일반 문서에 있는 광고 호스트/바깥 컨테이너를 선택합니다. 위치 기반 개별 규칙은 사이트 구조가 바뀌면 다른 요소를 가리킬 수 있으므로 미리보기와 복구 경로가 필요합니다. 첫 버전은 document_idle에서 적용하므로 초기 광고 깜빡임 0을 보장하지 않습니다. User Spell과 저장소/코드를 자동 공유하지 않습니다.

검증: `node --test tests/*.test.js` (13개). 실제 확장 브라우저 시나리오는 로컬 임시 `/tmp/mintool-hide-v3-probe.mjs`에 있으며 임시 Chrome 프로필만 사용합니다. 100개 그룹, 편집 재개/취소/전체 삭제, 외부 수정 충돌, 저장 실패 재시도, 드래그/축소/범위 보정, JSON과 초안 분리, dot 단일 표시/원래 hidden 자손 보존/키보드/390px 툴팁/중첩/스크롤 클리핑, 기존 스타일 편집기 드래그, 실제 티스토리의 5개 광고 래퍼를 검증했습니다. 충돌 방지 로직 제거 시 회귀 테스트가 실패하는 것도 확인했습니다. 요약형 패널의 상세 펼침/수정과 반투명 미리보기에서 원본 DOM·visibility·opacity가 유지되는지, 스크롤 컨테이너에 일부만 보이는 영역의 덮개가 정확히 잘리는지도 검증했습니다.

툴바 팝업 검증은 로컬 임시 `/tmp/mintool-toolbar-probe.mjs`에서 실제 Chrome action popup으로 수행합니다(13개). 기본/펼침 메뉴와 키보드, 활성 규칙 범위, 전역 기능 off, 다른 페이지 규칙만 켜진 경우, SPA URL 변경/늦은 응답 무시, 실패/재시도/중복 클릭 방지, 실제 패널 진입, 전체 해제의 데이터 보존, 제한된 페이지, 기존 설정/팝업 열기 기능을 확인했습니다.
