# Project Context: mintool-crx

이 문서는 AI 에이전트가 현재 프로젝트의 고유한 배경과 진행 상황을 파악하기 위한 전용 공간입니다.

## 1. 프로젝트 개요
- **목적**: 다양한 웹사이트(GitHub, TossInvest, Jira 등)에서의 생산성 향상 및 광고 차단, DOM 조작 등의 기능을 제공하는 다목적 도구 상자(Toolbox) 크롬 확장 프로그램입니다.
- **주요 기능**:
    - **GitHub 확장**: PR 커밋 자동 임베드, 알림 필터링, 단축키 등.
    - **광고 차단**: `declarativeNetRequest` 및 사용자 정의 스크립트를 통한 광고 탐색 및 제거.
    - **DOM 관리**: 요소 제거/숨기기 및 Undo 기능. 별도의 **숨기기 모드**에서 visibility 미리보기로 선택한 규칙을 저장·재적용할 수 있습니다.
    - **사이트 커스텀**: TossInvest, Jira 등 특정 사이트 맞춤 기능.
    - **QA 시나리오**: (분석 중) QA 테스트 및 자동화를 위한 시나리오 스크립트 실행 기능으로 추정.

## 2. 진행 상황 및 히스토리
- **초기 상태**: MV3 기반으로 개발되었으며, `lib/` 폴더에 공통 유틸리티와 컴포넌트가 모여 있습니다.
- **현안**: `qa-scenario/script.js` 등 일부 파일이 매우 커져 있어 모듈화가 시급한 상태입니다.
- **아키텍처 도입**: `.agent/` 폴더를 통해 AI 협업 지침 및 표준 아키텍처 가이드라인이 도입되었습니다.

## 3. DOM 숨김 규칙 (선택·저장)

- 시작: 우클릭 → MinTool → **숨기기 모드 (선택·저장)**, 또는 팝업의 **숨기기 모드 시작**. 확장 업데이트 뒤에는 대상 페이지도 새로고침합니다.
- 요소 위에서 실제 visibility 숨김을 미리보고 클릭하면 후보에 추가됩니다. 기본 제안은 동일한 광고 속성/클래스의 그룹이며, 패널에서 **이 요소만** 또는 다른 그룹으로 바꿀 수 있습니다. selector와 매칭 개수를 표시합니다.
- **F2**: 대상 고정/해제. **↑/↓** 또는 버튼: 바깥/안쪽 요소 선택. 패널이 대상을 가리면 **패널 접기**. **Esc/취소**: 미저장 후보와 미리보기 복원.
- **저장하고 적용**에서 페이지 또는 사이트 범위를 선택합니다. 페이지는 pathname + query 일치(hash 제외), 사이트는 정확한 origin 일치입니다. 저장 성공 응답 뒤에만 닫히며, 실패하면 후보를 보존하여 재시도할 수 있습니다.
- 팝업에서 규칙별 해제/재적용/삭제, **이 사이트 전체 해제**를 제공합니다. 전체 해제는 삭제가 아닌 비활성화입니다. 설정의 **DOM 숨김 규칙**을 끄면 열린 선택 모드와 적용 스타일도 해제됩니다.

### 책임 경계와 파일

- `configs/dom-hider.global.js`: 저장 키·메시지·후보 속성·제한의 정의.
- `services/dom-hider/rules.global.js`: 규칙 검증/범위 매칭/visibility CSS의 단일 정의. 미리보기와 영구 적용은 이 CSS 생성기를 함께 사용합니다.
- `selector.global.js`: CSS.escape를 적용한 요소/그룹 후보 생성. 개별 선택의 위치 경로는 루트나 고유 ID에 고정하며, 현재 우연히 하나만 매칭되는 상대 경로를 저장하지 않습니다.
- `picker.global.js` + `picker-ui.global.js`: 선택 세션과 Shadow DOM 패널. hit-test 동안만 우리 스타일을 동기적으로 비활성화하고 paint 전에 복원해, 숨긴 대상 뒤의 요소로 선택이 튀는 것을 방지합니다. 투명 입력층으로 iframe 내부 이벤트 없이 바깥 iframe 박스를 선택합니다.
- `storage.background.js`: chrome.storage.local의 `domHideRulesV1`을 소유하는 단일 쓰기 경로. 여러 탭의 read/modify/write를 직렬화해 덮어쓰기를 방지합니다.
- `content-isolated.js`: 저장/기능 설정 변경과 SPA 경로 변경에 맞춰 재적용. CSS가 나중에 생긴 매칭 요소도 가립니다. 요소별 영구 rAF 루프를 만들지 않습니다.
- `popup/dom-hide-rules.js`: 페이지 UI를 잘못 숨겨도 접근 가능한 복구 경로.

### 지원 범위와 검증

광고 자동 판별이나 네트워크 차단 기능이 아닙니다. 확인한 selector를 visibility:hidden으로 적용하며 DOM·iframe과 공간은 제거하지 않습니다. 기존 DOM 가리기/제거/Ad Block과 별도 기능입니다. iframe 내부 문서나 Shadow DOM 내부의 선택은 지원하지 않으며, 광고 전체는 일반 문서에 있는 광고 호스트/바깥 컨테이너를 선택합니다. 위치 기반 개별 규칙은 사이트 구조가 바뀌면 다른 요소를 가리킬 수 있으므로 미리보기와 복구 경로가 필요합니다. 첫 버전은 document_idle에서 적용하므로 초기 광고 깜빡임 0을 보장하지 않습니다. User Spell과 저장소/코드를 자동 공유하지 않습니다.

검증: `node --test tests/*.test.js`. 실제 확장 브라우저 시나리오는 로컬 임시 `/tmp/mintool-hide-probe.mjs`에 있으며 임시 Chrome 프로필만 사용합니다.
